# NOORÉ Social Links Setup

All public social/contact links are centralized in:

`src/config/social-links.ts`

Replace these placeholder values when you are ready:

- `instagram` → your Instagram profile
- `facebook` → your Facebook page
- `twitter` → your X/Twitter profile
- `tiktok` → your TikTok profile
- `youtube` → your YouTube channel
- `whatsapp` → your WhatsApp chat link

The footer already uses these links, and the floating WhatsApp button uses the same WhatsApp value.

No other theme/layout changes are required.
